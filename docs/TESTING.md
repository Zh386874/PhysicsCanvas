# 测试文档

> 本文档描述物理解模项目的测试策略、测试用例和未来测试计划。

---

## 一、测试现状

### 1.1 当前状态

项目目前**无自动化测试**，物理引擎正确性依赖手动验证。本文档定义测试策略，供后续补齐测试时参考。

### 1.2 测试目标

| 目标 | 说明 |
|------|------|
| 物理引擎正确性 | 验证力模型、碰撞检测、积分方法的数学正确性 |
| 回归防护 | 防止修复一个 bug 时引入新 bug |
| 题库场景验证 | 确保每道真题加载后行为符合物理预期 |
| UI 交互可靠性 | 验证编辑器工具、拖拽、框选等交互 |

## 三、单元测试用例

### 3.1 物理引擎测试（usePhysics.ts）

#### 测试 1：重力自由落体

```
给定：质量 1kg 物体，初始位置 (0, 0)，初速度 (0, 0)，重力 490 px/s²
操作：updatePhysics(0.016) 执行 60 帧（1 秒）
期望：
  - 最终 y ≈ 0.5 × 490 × 1² = 245 px（自由落体公式）
  - 最终 vy ≈ 490 px/s
  - x 不变，vx 不变
```

#### 测试 2：平抛运动

```
给定：质量 1kg，位置 (0, 0)，初速度 (500, 0) px/s，重力 490 px/s²
操作：updatePhysics(0.016) 执行 60 帧
期望：
  - 最终 x ≈ 500 px（水平匀速）
  - 最终 y ≈ 245 px（垂直自由落体）
  - vx 不变 = 500
  - vy ≈ 490
```

#### 测试 3：弹簧简谐振动周期

```
给定：质量 0.5kg，弹簧 k=10N/m，自然长度 150px，初始形变 50px
操作：updatePhysics(0.016) 执行至完成一个周期
期望：
  - 周期 T ≈ 2π√(m/k) = 2π√(0.5/10) ≈ 1.40s
  - 振幅保持 50px（能量守恒，误差 < 5%）
```

### 3.2 碰撞检测测试（useCollision.ts）

#### 测试 4：弹性碰撞动量守恒

```
给定：球A m=1kg v=500px/s，球B m=2kg v=0，恢复系数=1
操作：checkParticleCollision(a, b, 1.0)
期望：
  - 碰撞后 vA = ((1-2)×500 + 2×2×0) / 3 = -166.7 px/s
  - 碰撞后 vB = ((2-1)×0 + 2×1×500) / 3 = 333.3 px/s
  - 动量守恒：1×(-166.7) + 2×333.3 = 500 = 初始动量
  - 动能守恒：0.5×1×166.7² + 0.5×2×333.3² = 初始动能
```

#### 测试 5：完全非弹性碰撞共速

```
给定：球A m=2kg v=400px/s，球B m=3kg v=0，恢复系数=0
操作：checkParticleCollision(a, b, 0)
期望：
  - 碰撞后 vA = vB = (2×400 + 3×0) / 5 = 160 px/s（共速）
  - 动量守恒：2×160 + 3×160 = 800 = 初始动量
```

#### 测试 6：地面碰撞反弹

```
给定：球 r=15px，y=385px，vy=200px/s，groundY=400，恢复系数=0.6
操作：checkGroundCollision(obj, 400, 0.6)
期望：
  - y 修正为 385px（groundY - radius）
  - vy = -200 × 0.6 = -120 px/s
  - 返回 true
```

#### 测试 7：法线自动计算

```
给定：线段 (0,0) → (4,3)（斜面）
操作：autoComputeNormal({ x1:0, y1:0, x2:4, y2:3 })
期望：
  - dx=4, dy=3, len=5
  - nx = dy/len = 0.6, ny = -dx/len = -0.8
  - normalY < 0（指向上方）
```

### 3.3 工具函数测试

## 四、题库场景验证

### 4.1 验证方法

每道真题加载后，检查以下条件：

| 检查项 | 方法 |
|--------|------|
| 物体位置正确 | 加载后截图，对比预期位置 |
| 初始速度正确 | 检查 state.objects 中 vx/vy 值 |
| 播放无报错 | 播放 20 秒，控制台无错误 |
| 物理行为合理 | 观察运动轨迹是否符合物理规律 |
| 无卡顿 | FPS > 30（子步数 < 200） |

### 4.2 关键场景验证清单

| 题目 ID | 验证重点 |
|---------|----------|
| slope-002 | 滑块在粗糙斜面上减速下滑 |
| collision-002 | 碰撞后两球共速移动 |
| magnetic-001 | 粒子做圆周运动，半径 r=mv/(qB) |
| electric-003 | 液滴悬浮静止（qE=mg） |
| spring-001 | 振子周期性振动，振幅不发散 |
| conveyor-001 | 物体加速到传送带速度后匀速 |
| plate-001 | 滑块和木板相对滑动 |

## 六、性能测试

### 6.1 FPS 监控

```javascript
// 在浏览器控制台执行
let frames = 0
let lastTime = performance.now()
function measure() {
  frames++
  const now = performance.now()
  if (now - lastTime >= 1000) {
    console.log(`FPS: ${frames}`)
    frames = 0
    lastTime = now
  }
  requestAnimationFrame(measure)
}
measure()
```

### 6.2 性能基准

| 场景 | 目标 FPS | 子步数/帧 | 说明 |
|------|----------|-----------|------|
| 常规力学（3 物体） | ≥ 60 | 1-2 | 无压力 |
| 碰撞（3 球连环） | ≥ 60 | 1-3 | 碰撞瞬间子步增加 |
| 磁场（宏观参数） | ≥ 60 | 1-4 | 参数已优化 |
| 电场（宏观参数） | ≥ 60 | 1-4 | 参数已优化 |
| 弹簧（k=10-20） | ≥ 60 | 1-2 | 数值稳定 |
| 极端情况（MAX_SUBSTEPS） | ≥ 30 | ≤ 200 | 上限保护 |
