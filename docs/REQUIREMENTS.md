## 一、项目概述

### 1.1 创意名称
**物理解模**（PhysicsCanvas）

### 1.2 项目定位
基于 Vue 3 + Canvas 2D 的网页应用（Web App），物理仿真教学工具，覆盖高中物理力学与电磁学常见题型，内置高考真题库与 AI 题目解析能力。

### 1.3 核心价值
| 维度 | 描述 |
|------|------|
| 效率提升 | 将抽象物理过程可视化，让理解从"抽象推理"变为"直观观察" |
| 社会价值 | 让优质物理教育资源更普惠，不依赖名师讲解、不需要昂贵实验设备 |

### 1.4 解决的问题
高中物理大题（尤其是高考真题）中的运动过程、力学分析、电磁场变化等抽象概念，仅靠文字和静态图难以理解，学生经常"看懂答案但想不通过程"。

## 二、目标用户与使用场景

### 2.1 目标用户
| 用户群体 | 优先级 | 核心诉求 |
|----------|--------|----------|
| 高中物理学生（备考高考） | P0 | 做题时遇到不理解的运动过程，需要直观演示 |
| 高中物理教师 | P1 | 备课需要可视化演示素材，可自由搭建场景 |

### 2.2 使用场景
1. **做题辅助**：学生做题时遇到不理解的物理过程，输入题目或选择真题，一键生成动态模拟
2. **考前复习**：复习高考真题时，观察完整运动过程与受力分析，理解过程而非记忆答案
3. **教师备课**：教师自定义搭建物理场景，生成可交互演示用于课堂教学
4. **参数探究**：调节物体质量、初速度、场强等参数，观察物理过程的变化规律

### 2.3 用户痛点
- 静态图 + 文字无法直观理解动态物理过程
- 看答案能看懂但自己想不通过程
- 历年高考真题缺乏配套的动态模拟资源

#### FR-3 物理引擎 ✅
| 编号 | 需求项 | 验收标准 |
|------|--------|----------|
| FR-3.1 | 欧拉积分 + 子步防隧穿 | 动态子步数，上限 MAX_SUBSTEPS=200，单步 ≤10px |
| FR-3.2 | 三类碰撞检测 | 地面碰撞、质点间碰撞、线段连续碰撞(CCD) |
| FR-3.3 | 摩擦力模型 | 帧率无关线性减速 a=μgcosθ，Δv=a·dt，优先取线段摩擦系数 |
| FR-3.4 | 支持的力 | 重力 mg、自定义力、电场力 qE、洛伦兹力 qvB、弹簧力 -kx |
| FR-3.5 | 8 大场景模型 | 抛体、斜面、弹性碰撞、磁场圆周、电场偏转、弹簧振子、传送带、板块模型 |
| FR-3.6 | 板块模型牛顿第三定律 | 可移动线段受反作用冲量，velocity 字段记录线段速度；上/下表面摩擦分离（frictionTop/frictionBottom） |
| FR-3.7 | 单位制 | SI 国际单位输入，PIXELS_PER_METER=50 转像素，重力内部存 490 px/s² |
| FR-3.8 | 弧线约束动力学 | 小球进环后约束在弧面做无能量损耗圆周运动，满足自然脱离条件时解除（constraintEnabled/constrainedArcGroupId） |
| FR-3.9 | 触发器缺口机制 | 圆环动态缺口（entryGap/exitGap），支持 enterRing（进环触发）/angleCross（角度穿越触发）两种触发类型，控制缺口开闭 |

### 4.3 物理准确性验收
| 场景 | 验收要点 |
|------|----------|
| 抛体运动 | 轨迹为抛物线，水平速度恒定，竖直方向匀加速 |
| 斜面滑块 | 沿斜面方向加速度 a=g(sinθ-μcosθ)，法线方向受力平衡 |
| 弹性碰撞 | 动量守恒 + 动能守恒，restitution=1 |
| 磁场圆周 | 洛伦兹力提供向心力，半径 r=mv/(qB) |
| 电场偏转 | 类抛体运动，加速度 a=qE/m |
| 弹簧振子 | 周期 T=2π√(m/k)，简谐运动 |
| 传送带 | 摩擦力基于相对速度，共速后摩擦力消失 |
| 板块模型 | 牛顿第三定律，物块与板块加速度符合预期 |

## 五、非功能需求

### 5.1 性能
- 常规场景（≤10 物体）稳定 60fps
- 极端场景（电磁场微观粒子）通过参数宏观等效化避免子步爆炸
- 子步数硬上限 MAX_SUBSTEPS=200，防止计算量爆炸

### 5.2 可维护性
- 单一职责：每个 composable 只负责一类逻辑
- 单向数据流：usePhysics.state 是唯一数据源，组件通过 props/emit 通信
- 类型安全：核心 composables 使用 TypeScript，消除 any 类型
- 常量集中管理：魔法数字统一至 src/constants.ts

### 5.3 可部署性
- GitHub Pages 自动部署（GitHub Actions）
- 本地运行：`npm install && npm run dev`
- 无后端依赖（AI 解析为客户端直连 DeepSeek API）

### 5.4 兼容性
- 现代浏览器（Chrome / Edge / Firefox 最新版）
- 桌面端优先（移动端为 P2 规划）
- 高 DPI 屏幕适配

### 7.2 关键技术决策
| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | Vue 3 + Composition API | 响应式系统适合物理状态管理 |
| 渲染方案 | Canvas 2D | 高性能绘制，适合大量物体 |
| 状态管理 | Composables（非 Pinia） | 物理状态为全局单例，无需 store 复杂性 |
| 单位制 | SI 输入 + 像素内部存储 | 兼顾用户习惯与渲染性能 |
| AI 接入 | DeepSeek API | 客户端直连，无后端依赖 |
